# 함닷 (HAMDOT) v1.4

세특 문장은 "~함."으로 끝납니다. 그 문장을 쓰고 점검하는 도구라서 함닷입니다.

학교생활기록부 서술형 항목(과목별 세부능력 및 특기사항, 자율·자치·동아리·진로활동 특기사항, 행동특성 및 종합의견)을 쓰고 점검하는 웹 도구입니다.

- 바이트 계산: 한글 등 3Byte, 그 외 1Byte, 엔터 1Byte (2026 학교생활기록부 기재요령 p.208)
- 필터링: 기재요령의 기재 불가·지양 항목을 근거 쪽수와 함께 표시
- NEIS 엑셀 연동: [과목별세부능력및특기사항] {엑셀내려받기} 파일을 불러와 학급 전체를 점검하고, 세특 열만 채워 다시 저장
- 패턴 틀, 맞춤법 검사기 연결, 서울대 아로리 '나도 입학사정관' 사례 색인(원문 링크)

엑셀과 입력한 문장은 브라우저 안에서만 처리하며 서버로 보내지 않습니다. 학생 작업 내용은 기본으로 이 탭에서만 유지하며, 탭을 닫으면 사라집니다. “이 기기에 계속 저장”을 켜면 다음에도 불러올 수 있습니다. 공용 컴퓨터에서는 작업 후 “저장 내용 지우기”를 눌러 주세요. 자세한 내용은 [출처와 라이선스](licenses.html)를 보세요.

승현이 Claude(Anthropic)와 협업해 만들었습니다. 기재 판단의 최종 책임은 입력하는 교사에게 있으며, 이 도구의 표시는 보조 의견입니다.
